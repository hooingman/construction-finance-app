# 3분 시연과 배포 전 점검

## 시연 순서

1. 0:00~0:30 — 홈: 건설기업 종목 2~3개를 보유한 개인 투자자의 재무분석 문제 설명.
2. 0:30~1:00 — 재무현황: 현대건설·2024년, 재무 규모·ROA·ROE·유동비율·현금흐름과 선택형 추이.
3. 1:00~1:30 — 기업 비교: 현대건설·GS건설·2024년, 수익성·안정성·성장성·현금흐름 비교표와 선택 차트. 연결·별도 구분 설명.
4. 1:30~2:00 — 예측: 현대건설·2024년 기준, Ridge 회귀로 2025년 예상. 입력 지표·연도 분할 평가와 평균 기준선 비교 설명.
5. 2:00~2:30 — AI 활용: 계정명 추출 누락을 ID 기반 RAW 대조로 복구한 사례 설명.
6. 2:30~3:00 — 질문: 데이터 출처, 기준 연도 이후 값 제외, 3년 자료 부족 처리.

## 예상 질문

- 계산은 어디서 하는가? 평균은 core.py, 회귀 학습·평가는 ml.py, 화면은 pages/, CSV 캐시는 ui.py다.
- 왜 Ridge인가? 재무비율 간 상관성이 있어 계수 규제로 시작했다. 3년 평균·전년도 값과 동일 검증 행에서 오차를 비교한다.
- 데이터는 검증했는가? 저장된 RAW 전체와 대조했고, 정정 공시 재조회는 수행하지 않았다.
