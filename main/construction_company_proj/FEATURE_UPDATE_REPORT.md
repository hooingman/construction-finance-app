# 상세 재무정보·기업 비교·회귀 예측 확장

## 변경

- 재무현황: 재무 금액 6개, 수익성 4개, 안정성 3개, 성장성 3개, 현금흐름 4개. 선택형 추이와 연도별 상세 표.
- 기업 비교: 수익성·안정성·성장성·현금흐름별 같은 연도 비교표와 분류별 지표 차트.
- 예측: Ridge 회귀 기본, 최근 3년 평균 선택 가능. 입력 지표·학습 범위·MAE/RMSE/R²와 단순 기준선 비교 표시.
- 자본이 0 이하일 때 해석 안내. 성장률은 같은 기준·연속 전년·양수 분모일 때만 계산.

## 데이터

저장된 RAW에서 11개 원천 항목 4,169건 중 4,167건을 추출했다. CNT85 2015·상지건설 2018의 순이익은 자료 없음으로 유지했다. 나머지 계정과 현금흐름은 추출됐다. 이전 full_ml 대비 124개 셀 복구/재계산. 기말 자산·자본 기준 ROA·ROE임을 명시했다.

## 검증

개발 환경·별도 Python 3.12 가상환경에서 각각 pytest 20개 통과. 미래 자료 변경에 대한 과거 예측 불변성, 연도 단절·기준 변경의 타깃 제외, 기업 비교 분류, 평균 방식 유지, 자료 부족 안내를 검증했다.
최신 브라우저 실행 결과는 artifacts/BROWSER_REPORT.md, 캡처와 영상은 artifacts/에 저장한다.

초기 2023~2025 검증에서 MAE(%p)는 Ridge 8.96, 전년도 값 8.63, 최근 3년 평균 11.20이다. 회귀가 모든 기준선보다 낫다는 결론은 내리지 않았다. 자세한 설계는 ML_DESIGN.md를 참고한다.

기존 PRE_DEPLOY_REPORT.md와 최초 체크리스트의 15개 테스트·규칙 기반 한정 범위는 이전 MVP 시점의 기록이다. 이 문서와 확장된 SPEC.md가 최신 범위다. 실제 배포는 수행하지 않았다.
