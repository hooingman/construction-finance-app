# 기능 명세

사용자: 건설업종 종목 2~3개를 보유하고 실적 발표 후 확인 가능한 재무자료로 다음 해 수익성을 가늠하려는 개인 투자자.

| ID | 사용자 스토리 | 우선순위 | 완료 조건 |
|---|---|---|---|
| US-1 | 기업의 재무상태와 추이를 자세히 파악하고 싶다. | Must | 기업·연도 선택 → 금액 6개, 수익성·안정성·성장성·현금흐름, 선택형 추이와 상세 연도 표 |
| US-2 | 다른 건설기업과 수익성·안정성·성장성을 비교하고 싶다. | Must | 기업 2~3개·공통 연도 → 네 분류별 표, 분류별 지표 선택 차트 |
| US-3 | 재무지표를 종합해 다음 해 영업이익률을 추정하고 싶다. | Must | 기준 연도까지의 정답으로 학습한 Ridge 회귀 → 예상값·입력·학습 범위·기간 분할 평가, 평균 방식 선택 가능 |

화면 매핑: 재무현황=US-1, 기업비교=US-2, 영업이익률예측=US-3. 홈에는 사용자·문제·기능 소개.
로직과 데이터 처리는 core.py·ml.py, CSV 캐시는 ui.py, 화면은 pages/에 분리한다.

교수님이 제안한 작은 워크숍 MVP를 완성한 후 사용자의 요청에 따라 기획서의 상세 조회·비교와 회귀 예측 범위로 확장했다. ML은 현재 범위에 포함한다. 로그인·실시간 DART 조회·뉴스 분석·매매 추천·REST API·실제 배포는 제외한다.

## 구현 기준

- 결측은 화면에 자료 없음. 회귀 입력 보완은 학습 집합 통계만 사용.
- 금액은 억 원, 비율은 %, 영업이익률 변화는 %p.
- ROA/ROE는 기말자산·기말자본 기준. 자본이 0 이하이면 해석 안내.
- 성장률은 연속 연도·동일 재무제표 기준이며 전년 분모 양수일 때만 계산.
- 다음 해 정답도 연속 연도·동일 기준일 때만 연결. 기준 연도 이후 자료는 학습 금지.
- 평가 정답 2022년까지 학습, 2023년 이후 중 알려진 정답으로 검증. 이른 기준 연도는 경계를 앞당김.
- 기준선과 동일한 검증 행에서 MAE·RMSE·R²를 표시. 세부는 ML_DESIGN.md.
