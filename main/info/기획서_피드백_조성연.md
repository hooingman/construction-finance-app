# 프로젝트 기획서 피드백

이름: 조성연 (23007113)
주제: 건설기업 재무지표 기반 차년도 영업이익률 예측 서비스
판정: 통과

## 1. 조건 4개 점검

| 조건 | 판정 | 근거 |
|---|---|---|
| 5주차 시연 가능 | ○ | 기업·연도 선택 → 지표와 추이, 기업 간 비교, 예측 화면. 확보한 CSV로 4주차 안에 가능합니다. |
| 데이터가 있다 | ○ | OpenDART에서 건설기업 35개의 2015~2025년 재무제표를 수집해 분석용 데이터셋까지 확보했습니다. |
| 예측 기능이 붙는다 | ○ | 주요 재무지표 → 차년도 영업이익률(%). 회귀 문제가 명확하고 실제값과 예측값 비교 화면까지 설계했습니다. |
| 사용자가 구체적 | △ | "투자자 및 기업분석 사용자"는 집단입니다. |

## 2. 잘한 점

데이터 수집을 이미 끝내고 활용 열을 구체적으로 나열한 점, 외부 요인으로 예측 정확도가 제한될 수 있다는 리스크를 인정하고 성능이 낮으면 평가 지표와 오차를 함께 보여 주는 분석 중심 서비스로 전환하겠다는 대안이 정직합니다. 경영학 전공자로서 지표 선택(ROA, ROE, 유동비율 등)에 근거가 있습니다.

## 3. 4주차 체크포인트 1(0:40) 전에 고칠 것

1. 사용자를 한 사람으로 쓰세요. 예를 들어 "건설업종 종목 2~3개를 보유하고 연말 실적 발표 전에 내년 수익성을 가늠해 보려는 개인 투자자"처럼 적으면 화면 문구와 기본 선택 기업이 정해집니다.
2. 기능마다 사용자 스토리 한 문장과 만드는 순서가 없습니다. 기능 3부터 "core.py에 규칙 기반 예측 함수(예: 최근 3년 영업이익률 평균) → pytest → 폼 → 결과"로 적고, 기능 1·2는 "CSV 로드(캐시) → 기업 선택 → 지표 → 차트" 순서로 적으세요.
3. 기업 35개 × 연도 10개면 행이 350개 안팎입니다. 1단계 데이터 탐색 화면은 이 크기에 맞게 기업별 추이 하나, 비교 지표 3개 정도로 작게 잡으세요. 서버 아이디와 프로젝트 폴더는 적었으니 폴더명을 영문 소문자로 통일하면 좋습니다.

## 4. 2·3단계 연결 메모

회귀 문제이고 표본이 작으므로 2단계에서 가장 중요한 것은 분할 방식입니다. 같은 기업의 다른 연도가 학습과 검증에 섞이면 점수가 부풀려지니, 2015~2022년으로 학습하고 2023년 이후를 검증하는 연도 기준 분할을 쓰세요. 피처는 지표 자체보다 전년 대비 변화율이 더 설명력이 높을 가능성이 큽니다. 영업이익률은 적자 기업에서 큰 음수가 나오므로 이상치 처리 기준을 7주차에 미리 정해 두세요.
